Privacy policy

Last updated: November 2, 2026

PixelCode Studio is a personal tool that the owner of the PixelCode Academy YouTube channel uses to manage that channel. It is not offered to other users.

What the tool accesses

With the channel owner's permission, the tool uses the YouTube Data API to upload the channel's own videos and thumbnails, edit their titles, descriptions, tags, privacy and publish times, manage the channel's playlists, and read view, like and comment counts for the channel's own videos.

How data is stored

The sign-in token is stored only on the channel owner's own computer. No data is sent to any server other than Google's. Nothing is sold, shared or used for advertising.

Other people's data

The tool does not collect personal information about viewers or any other users.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Google and YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
