PixelCode Studio

PixelCode Studio is the private publishing tool behind the PixelCode Academy YouTube channel, which teaches C++ programming with pixel-art videos.

The tool is used only by the channel owner. It uses the YouTube Data API to upload the channel's own videos, set their titles, descriptions, thumbnails and publish times, add them to the channel's playlists, and read their view statistics.

It is not offered to the public, and it does not access anyone else's account.
